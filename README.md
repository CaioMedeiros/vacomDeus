O projeto é um Sistema de Gerenciamento de Estoque de Suplementos em Java. 
Lojas e academias precisam controlar quais suplementos possuem, em que quantidade e se estão dentro do prazo de validade. 
Sem esse controle, produtos vencidos podem ser vendidos, gerando prejuízo e risco ao consumidor. 
Para resolver isso, o sistema foi construído inteiramente com os pilares da Programação Orientada a Objetos
